## Change 1 — Stability + scroll pass instead of `sleep(1500)`

**Files / functions**
- `extension/content/analyzer.js` — **add** exported, self-contained `scrollAndSettle(opts)` (injected functions must not reference module scope — Chrome serializes their source).
- `extension/background.js` — **modify** `analyzeInTab()`; **update its two callers** (`runAnalyze`, `runRebuild` loop) to destructure the new return shape and log settle stats.

**A. Add to `extension/content/analyzer.js`** (next to `analyzePage`):

```js
// Progressive scroll + quiescence detection. Scroll in ~0.9-viewport steps to
// trigger lazy loaders, then wait until DOM mutations AND network activity
// stop (or a hard deadline passes), then scroll back to top for analysis.
export function scrollAndSettle(opts) {
  const STEP_MS = (opts && opts.stepMs) || 350;
  const QUIET_MS = (opts && opts.quietMs) || 600;
  const DEADLINE_MS = (opts && opts.deadlineMs) || 12000;
  const MAX_SCREENS = 12;
  const start = Date.now();
  return new Promise((resolve) => {
    let lastMutation = Date.now();
    let lastResources = performance.getEntriesByType('resource').length;
    const mo = new MutationObserver(() => { lastMutation = Date.now(); });
    mo.observe(document.documentElement, { childList: true, subtree: true, characterData: true });
    let screens = 0, lastY = -1;
    (function step() {
      const y = window.scrollY;
      const atBottom = window.innerHeight + y >= document.documentElement.scrollHeight - 2;
      const noProgress = y === lastY;
      if (Date.now() - start > DEADLINE_MS || screens >= MAX_SCREENS ||
          (screens > 0 && (atBottom || noProgress))) return finish();
      lastY = y;
      window.scrollTo(0, y + Math.round(window.innerHeight * 0.9));
      screens++;
      setTimeout(step, STEP_MS);
    })();
    function finish() {
      (async () => {
        try { if (document.fonts && document.fonts.ready) await document.fonts.ready; } catch (e) {}
        const hardStop = Date.now() + 3000;
        while (Date.now() - lastMutation < QUIET_MS && Date.now() < hardStop) {
          const n = performance.getEntriesByType('resource').length;
          if (n !== lastResources) { lastResources = n; lastMutation = Date.now(); }
          await new Promise((r) => setTimeout(r, 250));
        }
        mo.disconnect();
        window.scrollTo(0, 0);           // restore top so sticky headers/fixed nav aren't duplicated
        setTimeout(() => resolve({ ms: Date.now() - start, screens }), 250);
      })();
    }
  });
}
```

**B. `extension/background.js` — `analyzeInTab()`**

Before:
```js
tab = await chrome.tabs.create({ url, active: false });
await waitComplete(tab.id);
await sleep(1500); // let lazy content / fonts settle
const [res] = await chrome.scripting.executeScript({ target: { tabId: tab.id }, func: analyzePage });
return res && res.result;
```
After:
```js
tab = await chrome.tabs.create({ url, active: false });
await waitComplete(tab.id);
let settle = { ms: 0, screens: 0 };
try {
  const [s] = await chrome.scripting.executeScript({ target: { tabId: tab.id }, func: scrollAndSettle });
  settle = (s && s.result) || settle;
} catch (e) { /* page blocks script injection — fall back to immediate analysis */ }
const [res] = await chrome.scripting.executeScript({ target: { tabId: tab.id }, func: analyzePage });
return res && res.result ? { model: res.result, settle } : null;
```
Import it: `import { analyzePage, scrollAndSettle } from './content/analyzer.js';`

**C. Callers**
- `runAnalyze`: `const model = await analyzeInTab(url)` → `const { model } = await analyzeInTab(url);` (keep the existing null check on `model`).
- `runRebuild` page loop: `const r = i === 0 && state.startModel ? { model: state.startModel } : await analyzeInTab(page.url);` and extend the existing log line with `settled in ${r.settle.ms}ms over ${r.settle.screens} screens`.

**Edge cases handled**
- *Never settles* (carousels/ads mutating forever): `DEADLINE_MS` + 3s hard stop in the quiet loop — worst case ≈ 15 s/page.
- *Infinite scroll*: `MAX_SCREENS` (12) and deadline cap total scrolling.
- *Scroll-jacked / non-scrolling pages*: `noProgress` check finishes after the first step.
- *Virtualized lists* (React Window removes off-screen DOM): analysis runs scrolled-back to top; anything removed by the framework is lost — accepted MVP limitation (document in README).
- *Background-tab timer throttling*: worst case extends the wall clock but the deadline still bounds it; `waitComplete` timeout (25 s) unchanged.
- *CSP blocks injected script*: the try/catch falls back to immediate analysis (today's behavior minus sleep).

## Change 2 — Blob in IndexedDB instead of base64 in `chrome.storage.local`

**Files / functions**
- `extension/background.js` — add `idbPutZip/idbGetZip/idbDelZip`, `downloadZip()`; add `downloadZip` message case; **modify** `runRebuild()` tail; **remove** `zipB64` from `IDLE`.
- `extension/popup.js` — replace the whole `btnDownload` b64-decode handler with a one-liner message.

**A. background.js — new helpers (top of file)**

```js
// ZIP blobs live in IndexedDB (Blob-efficient, survives service-worker
// restarts) instead of chrome.storage.local (JSON/base64, ~2.7x size).
const idb = (mode, fn) => new Promise((res, rej) => {
  const open = indexedDB.open('sr-zips', 1);
  open.onupgradeneeded = () => open.result.createObjectStore('zips');
  open.onsuccess = () => {
    const tx = open.result.transaction('zips', mode);
    const req = fn(tx.objectStore('zips'));
    tx.oncomplete = () => res(req && req.result);
    tx.onerror = () => rej(tx.error);
  };
  open.onerror = () => rej(open.error);
});
const idbPutZip = (name, blob) => idb('readwrite', (s) => s.put({ name, blob, created: Date.now() }, 'last'));
const idbGetZip = () => idb('readonly', (s) => s.get('last'));
const idbDelZip = () => idb('readwrite', (s) => s.delete('last')).catch(() => {});
```

**B. `runRebuild()` tail**

Before:
```js
const blob = buildZip(entries);
const zipBytes = new Uint8Array(await blob.arrayBuffer());
const zipB64 = bytesToB64(zipBytes);
...
s.zipB64 = zipB64; s.zipName = zipName;
s.summary = { ..., zipBytes: zipBytes.length };
```
After:
```js
const blob = buildZip(entries);
await idbPutZip(zipName, blob);          // no arrayBuffer/b64 copies at all
...

s.summary = { ..., zipBytes: blob.size };
```
Also delete `zipB64: ''` from the `IDLE` object, and in the `reset` message case call `void idbDelZip();`.

**C. Download path (background, not popup — blob URLs created in the popup die when it closes)**

Message case: `case 'downloadZip': void downloadZip(); break;`

```js
let zipObjectUrl = '';
async function downloadZip() {
  const rec = await idbGetZip().catch(() => null);
  if (!rec || !rec.blob) {
    void updateState((s) => { s.phase = 'error'; s.error = 'Package expired — please rebuild the site.'; });
    return;
  }
  if (zipObjectUrl) URL.revokeObjectURL(zipObjectUrl);
  const url = URL.createObjectURL(rec.blob);
  zipObjectUrl = url;
  const downloadId = await chrome.downloads.download({ url, filename: rec.name, saveAs: false, conflictAction: 'uniquify' });
  const cleanup = () => { URL.revokeObjectURL(url); if (zipObjectUrl === url) zipObjectUrl = ''; chrome.downloads.onChanged.removeListener(onChange); };
  const timer = setTimeout(cleanup, 120000);            // leak guard
  function onChange(delta) {
    if (delta.id === downloadId && delta.state && delta.state.current !== 'in_progress') { clearTimeout(timer); cleanup(); }
  }
  chrome.downloads.onChanged.addListener(onChange);
}
```

**D. popup.js**

Before (entire `btnDownload` handler decoding base64): replace with
```js
$('btnDownload').addEventListener('click', () => send({ type: 'downloadZip' }));
```

**Edge cases handled**
- *SW terminated between "done" and click*: IndexedDB persists; the message wakes the SW.
- *Blob-URL leaks*: revoked on download completion/interruption or a 120 s timer; only one object URL alive at a time.
- *Double-click / re-download*: `conflictAction: 'uniquify'`; repeated clicks reuse/revoke safely.
- *IDB unavailable/fails*: caught → clear error state; rebuild is cheap to re-run.
- `chrome.storage.local` state stays tiny (progress text only) — quota errors gone.

## Change 3 — Higher asset cap, timeouts, and per-asset status in the manifest

**Files / functions**
- `extension/background.js` — constants, `fetchAsset()`, the download loop in `runRebuild()`, `assetsIndex` construction, `summary`.
- `extension/popup.js` — richer "kept remote" note.
- WP plugin: **no code change required** — `SRI_Media::fallback_url()` already resolves non-`assets/` URLs remotely and `map_assets()` only rewrites `assets/`-prefixed strings; verify only.

**A. Constants + `fetchAsset`**

Before: `const MAX_ASSET_BYTES = 8 * 1024 * 1024;` and a bare `fetch` with no timeout.
After:
```js
const MAX_ASSETS = 250;
const MAX_ASSET_BYTES = 25 * 1024 * 1024;   // tunable
const MAX_TOTAL_ASSET_BYTES = 150 * 1024 * 1024;
const ASSET_FETCH_TIMEOUT_MS = 30000;

async function fetchAsset(url) {
  const ctrl = new AbortController();
  const kill = setTimeout(() => ctrl.abort(), ASSET_FETCH_TIMEOUT_MS);
  try {
    const res = await fetch(url, { credentials: 'omit', signal: ctrl.signal });
    if (!res.ok) throw new Error('HTTP ' + res.status);
    const buf = new Uint8Array(await res.arrayBuffer());
    if (buf.length > MAX_ASSET_BYTES) throw new Error('asset-too-large');
    return { mime: res.headers.get('content-type') || '', b64: bytesToB64(buf), size: buf.length };
  } finally { clearTimeout(kill); }
}
```

**B. Download loop in `runRebuild()`** — replace `const failed = []` with `const failed = [], tooLarge = [], overBudget = [];` and:

```js
try {
  const a = await fetchAsset(url);
  if (totalAssetBytes + a.size > MAX_TOTAL_ASSET_BYTES) { overBudget.push(url); assets[url] = null; }
  else { totalAssetBytes += a.size; assets[url] = { path, mime: a.mime, b64: a.b64, size: a.size, status: 'downloaded' }; }
} catch (err) {
  (err.message === 'asset-too-large' ? tooLarge : failed).push(url);
  assets[url] = null;   // element keeps the original remote URL
}
```
(`let totalAssetBytes = 0;` reset at rebuild start.)

**C. Manifest + summary** — extend `assetsIndex` entries to `{ url, mime, status: 'downloaded', size }` and add:
```js
pkg.assetFallbacks = [
  ...failed.map((url) => ({ url, status: 'failed' })),
  ...tooLarge.map((url) => ({ url, status: 'too-large' })),
  ...overBudget.map((url) => ({ url, status: 'over-budget' })),
];
```
`summary` gains `skippedLarge: tooLarge.length, overBudget: overBudget.length, totalAssetMB`. Popup's done-note shows the breakdown (`N failed, M >25 MB, K over budget — those assets load from the original site`).

**Edge cases handled**
- *Hung downloads*: 30 s AbortController timeout marks the asset `failed` → remote fallback; the loop never stalls.
- *WP host upload limits* (InfinityFree ≈ 10 MB `upload_max_filesize`): `wp_upload_bits` fails for big files → existing `fallback_url()` keeps the original remote URL, so pages still render; importer surfaces nothing broken. Verified via E2E below.
- *Package bloat*: 150 MB total budget; overflow assets degrade gracefully to remote URLs.
